## About me

I'm studying Multimedia Engineering at [Universidad de San Buenaventura Cali](https://usbcali.edu.co/) and finishing the Full-Stack Developer bootcamp at [Generation Colombia](https://colombia.generation.org). I build web apps with Spring Boot and Angular.

I've also been working on the cloud side. I deployed a web app to AWS: Docker containers on an EC2 instance, PostgreSQL on Amazon RDS, and CloudFront in front for HTTPS on a custom domain. Now I'm preparing for the AWS Certified Cloud Practitioner exam.

Outside of code, I run in the mountains and train to stay healthy for the long run.
